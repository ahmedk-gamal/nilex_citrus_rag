# 🍊 NILEX.AI – Citrus Disease Advisory RAG System

**A Retrieval-Augmented Generation (RAG) application for farmers and agricultural engineers in the Beheira Governorate, Egypt.**

---

## 📌 Overview
This system provides **instant, source‑cited expert advice** on **citrus and orange diseases** (causes, symptoms, treatments, and authorized pesticides). It uses a local vector database built from trusted agricultural PDFs, combined with a large language model via OpenRouter.

**Key features:**
- 📄 Loads Arabic PDF documents and cleans text (diacritics, normalization)
- 🧠 Chunks and embeds content using multilingual Sentence‑Transformers
- 🔍 Retrieves the most relevant knowledge from ChromaDB
- 💬 Generates answers with **explicit source citations** (file name, page number)
- 🌐 Streamlit web interface with secure API key handling

---

## 🛠️ Tech Stack
- **Python 3.12** (Conda environment recommended)
- **LangChain** – document loading, splitting, and retrieval
- **ChromaDB** – local vector database
- **Sentence‑Transformers** (`paraphrase-multilingual-MiniLM-L12-v2`) – embeddings for Arabic
- **OpenRouter API** – LLM access (GPT‑3.5‑Turbo or any model)
- **Streamlit** – interactive user interface

## 🚀 How to Run Locally

### 1. Clone the repository
\`\`\`bash
git clone https://github.com/YOUR_USERNAME/nilex_citrus_rag.git
cd nilex_citrus_rag
\`\`\`

### 2. Set up the environment (Conda strongly recommended)
\`\`\`bash
conda create -n nilex_env python=3.12 -c conda-forge
conda activate nilex_env
conda install numpy sentence-transformers pypdf chromadb -c conda-forge
pip install -r requirements.txt
\`\`\`

### 3. Add your PDF references
Place one or more Arabic PDF files inside the \`data/\` folder.

### 4. Build the vector store (first time only)
\`\`\`bash
python _05_create_chroma_store.py
\`\`\`
This will create a \`chroma_db/\` folder (which is included in the repository for immediate deployment).

### 5. Set your OpenRouter API key
Create a file \`.streamlit/secrets.toml\` with:
\`\`\`toml
OPENROUTER_API_KEY = "sk-or-v1-your-key-here"
OPENROUTER_MODEL = "openai/gpt-3.5-turbo"
\`\`\`
**Important:** Never commit this file to GitHub.

### 6. Launch the app
\`\`\`bash
streamlit run streamlit_app.py
\`\`\`
Your browser will open. Ask your question in Arabic or English, e.g., “أعراض مرض التصمغ في البرتقال وعلاجه”.

---

## ☁️ Deploy on Streamlit Cloud
1. Push this repository to GitHub (without \`.streamlit/secrets.toml\`).
2. Go to [share.streamlit.io](https://share.streamlit.io).
3. Create a new app, select the repository and the main branch, and set the main file to \`streamlit_app.py\`.
4. In the app’s **Secrets** section, add:
   \`\`\`
   OPENROUTER_API_KEY = "your-key"
   OPENROUTER_MODEL = "openai/gpt-3.5-turbo"
   \`\`\`
5. Deploy! The app will load the pre-built \`chroma_db\` and work instantly.

## 📚 Knowledge Domain
The vector database is built from agricultural references covering:
- Phytophthora Gummosis
- Citrus Canker
- Citrus Greening (HLB)
- Anthracnose
- Root rot
- Nutrient deficiencies (Zinc, Iron)
- Medfly (fruit fly)

Each document includes symptoms, causes, treatments, and authorized pesticides according to Egyptian agricultural guidelines.
